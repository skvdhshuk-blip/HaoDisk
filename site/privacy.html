隐私政策

生效日期：2026 年 9 月 6 日 · English

HaoDisk 不收集、上传、出售或共享个人数据。应用无需账号，没有广告、追踪、遥测或第三方分析 SDK。

所有分析都在本机进行

HaoDisk 读取你所选文件夹内的文件名、路径、类型、大小、文件身份及修改时间，用于统计、展示和清理前核对；不读取文件正文。

扫描元数据暂存于应用沙箱缓存目录内的 SQLite 索引，仅供当前扫描使用，不跨启动复用。重新扫描、切换或忘记授权时释放旧索引，正常退出时清理。异常退出遗留的索引会在后续启动时清理。

你决定访问范围

访问范围由 macOS 系统文件夹选择器和 App Sandbox 控制。部分受系统保护的目录仍可能无法读取。应用不会要求管理员权限、完整磁盘访问、辅助功能或网络访问。

应用会在自身沙箱内保存最近一次选择的文件夹授权书签，方便下次使用。你可以在“更多”菜单中选择“忘记文件夹授权”，删除此记录并释放当前访问。退出应用也会结束本次运行的访问。

每一次清理都需要确认

你检查并确认清单后，应用才调用 macOS 的移到废纸篓功能。HaoDisk 不会清空废纸篓，也不会把移入废纸篓的大小直接当作新增可用空间。

网站与支持服务

本网站托管在 GitHub Pages，不使用分析脚本、广告或追踪 Cookie。GitHub 可能为提供网站托管服务处理访问请求中的技术信息，具体见 GitHub 隐私声明。

你可以通过 GitHub Issues 联系我们。你主动提交的信息由 GitHub 按其政策处理。请勿在公开反馈中附带私人路径、个人文件清单或其他敏感信息。

Privacy Policy

Effective September 6, 2026. HaoDisk analyzes folders you choose locally on your Mac. It does not collect, transmit, sell or share personal data. It has no accounts, advertising, tracking, telemetry or third-party analytics SDKs.

HaoDisk reads file metadata to calculate sizes and verify items before a user-confirmed move to Trash. It does not read file contents. Scan metadata is temporarily indexed in SQLite in the app’s sandbox cache directory. Indexes are not reused across launches. Old indexes are released on rescan or access changes and removed on normal exit. Leftovers from terminated processes are removed on a subsequent launch.

Access is limited by the system folder picker and App Sandbox. The most recent folder permission bookmark is stored locally and can be deleted with “忘记文件夹授权” (Forget Folder Access). HaoDisk never empties Trash and does not request administrator, Full Disk Access, Accessibility or network access.

This website is hosted on GitHub Pages without analytics or tracking scripts. GitHub may process technical request data to provide hosting, under its privacy statement. Support is available through the repository’s public GitHub Issues. Please do not submit sensitive information or private file listings.
